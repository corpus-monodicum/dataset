# RoC 1741

Rom, Biblioteca Casanatense, 1741

Tropar

Nonantola | Ende 11. Jahrhundert oder Anfang 12. Jahrhundert

**Notation – Textschrift**

Notation von Nonantola auf 3 Blindlinien, farbige F- (oder f-) und c-Linien, F- und/oder c-Schlüssel. Italienische Minuskel.

## Herkunft und Geschichte

Die Herkunft aus Nonantola wird durch das umfangreiche Formular für den Patron Silvester sichergestellt. Strittig ist die chronologische Priorität gegenüber der Schwesterhandschrift RoN 1343.

Vorsignatur: C IV 2
