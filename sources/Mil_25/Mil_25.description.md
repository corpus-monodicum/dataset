# Mil 25

Mailand, Biblioteca Ambrosiana, D 25 sup.

Gradualfragment

Norditalien | 12. Jahrhundert

## Notation – Textschrift

Italienische Notation auf 3 Blindlinien, rote F- (oder f-) Linie, gelbe c-Linie, F- oder c-Schlüssel. Italienische Minuskel.

## Inhalt

| Folio | Inhalt |
| --- | --- |
| Vorderes Spiegelblatt | Gesänge für Gründonnerstag und Karfreitag (Antiphonen zum Mandatum, Tractus) |
| Hinteres Spiegelblatt | Gesänge für den Ostersonntag (Graduale, Alleluia, Einleitungstropus zum Offertorium) |

## Herkunft und Geschichte

Die zwei nicht abgelösten Einbandfragmente stammen vermutlich aus derselben Handschrift. Baroffio lokalisiert sie aufgrund der Notation in der Nähe von Modena (**Baroffio** 2007).
