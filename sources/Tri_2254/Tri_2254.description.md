## Herkunft und Geschichte

Die Handschrift stimmt sehr genau mit Be 664 überein, daher ist gleiche Herkunft anzunehmen (s. dort); beide Handschriften waren zuvor im Besitz von Peter Bohn. Eine dritte Handschrift gleicher Herkunft aus dem Pfarrarchiv Ediger wurde von Husmann beschrieben (**Husmann** 1962).
